# 📽️ Projeto Clone Netflix

Este projeto consiste na recriação da interface da Netflix do zero, com o objetivo de **estudar e aprender conceitos na teoria e vê-los funcionando na prática**. Ao longo do desenvolvimento, explorei diversas tecnologias e ferramentas para estruturar, estilizar e integrar funcionalidades do site, compreendendo melhor a interação entre **front-end e back-end**.

---

## 🚀 Tecnologias e Ferramentas Utilizadas

### 🔹 **Design**
- Figma - Criação da interface visual para web e mobile.

### 🔹 **Front-end**
- HTML5 - Estruturação da página.
- CSS3 - Estilização e responsividade.
- JavaScript - Interatividade e manipulação do DOM.
- ReactJS - Integração entre o front-end e o back-end.

### 🔹 **Back-end**
- Node.js - Ambiente de execução do servidor.
- Express - Framework para facilitar a criação de APIs.
- MongoDB - Banco de dados NoSQL utilizado para armazenar as informações.
- Mongoose - ODM para interação com o MongoDB.
- Morgan - Middleware para registro de requisições.
- CORS - Gerenciamento de acessos entre domínios.
- JSON - Manipulação de dados e comunicação com a API.

### 🔹 **Banco de Dados**
- MongoDB - Armazenamento e gerenciamento das informações da aplicação.

### 🔹 **Ferramentas Adicionais**
- Insomnia - Testes de APIs e requisições CRUD.

---

Este projeto foi desenvolvido com o intuito de aprofundar meus conhecimentos em **desenvolvimento web**, compreendendo a integração entre **front-end e back-end** e aplicando conceitos estudados na prática.
